# Cmd+F website

The website for Cmd+F, served by GitHub Pages at https://brundonsmith.github.io/cmd-f/.

This repo is published automatically from the app's (private) repository, where the site lives in
`docs/`. Edits made here directly will be overwritten by the next publish, so make changes there instead.
